# Plot Twist v17: More decor, no hints on the map

Date: 2026-11-03. Code: commit [`716d757`](https://github.com/davidelatorre004/Introduction-to-Programming-2/tree/716d757c82f9b9c9e258ca639d4791d5d4110d71/plot_twist).

## What changed

- 53 new pieces of decor in every room: barrels, crates, lanterns, chairs, the captain's desk and log, crystals, puddles, an anchor and a fishing net.
- The map no longer blinks on the rooms where the anvil or the tinctures wait: they are found by exploring.

## How to play this version

From the folder `Introduction-to-Programming-2`:

```
git checkout 716d757
cd plot_twist
uv run python main.py
```

To go back to the latest version: `git checkout main`.
