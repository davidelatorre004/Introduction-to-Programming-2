# Plot Twist v05: 8-bit graphics

Date: 2026-10-01. Code: commit [`f272761`](https://github.com/davidelatorre004/Introduction-to-Programming-2/tree/f2727619065f764ce000c62943a4997686a6b7c1/plot_twist).

## What changed

- `sprites.py` draws every picture as text, one letter per pixel: the player walking in four directions, items, doors, characters, the ship and the room tiles.
- `pixel_font.py`: an original pixel font.
- Rooms fade in after a door; both endings are animated (dawn and coast, or the explosion).

## How to play this version

From the folder `Introduction-to-Programming-2`:

```
git checkout f272761
cd plot_twist
uv run python main.py
```

To go back to the latest version: `git checkout claude/funny-ramanujan-ffrx60`.
