# Plot Twist v02: Saving and loading

Date: 2026-10-01. Code: commit [`d36c765`](https://github.com/davidelatorre004/Introduction-to-Programming-2/tree/d36c765d0998e310372b6b7de94e8a3824abab05/plot_twist).

## What changed

- `save.py` writes the game as versioned JSON, through a temporary file, so a save is never left half-written.
- A missing, broken or outdated save file is treated as no save at all.
- The tests never touch the real save file (`conftest.py`).

## How to try this version

From the folder `Introduction-to-Programming-2`:

```
git checkout d36c765
cd plot_twist
uv run pytest
```

There is no window in this version: the tests play the game.

To go back to the latest version: `git checkout claude/funny-ramanujan-ffrx60`.
