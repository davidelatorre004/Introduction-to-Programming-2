# Plot Twist v06: The generators of the cabin

Date: 2026-10-06. Code: commit [`67bc2f5`](https://github.com/davidelatorre004/Introduction-to-Programming-2/tree/67bc2f53342d26cbe49a9533c817b601eddc30cd/plot_twist).

## What changed

- Four generators A-D: each one flips itself and the two wired to it. All four on dissolves the barrier around the altar and frees the key.
- The generators go back to their start every time the player walks in, until the puzzle is solved.
- Cables light up between generators that are both on.
- Also in this version: a play guide in Italian (`README.md`).

## How to play this version

From the folder `Introduction-to-Programming-2`:

```
git checkout 67bc2f5
cd plot_twist
uv run python main.py
```

To go back to the latest version: `git checkout claude/funny-ramanujan-ffrx60`.
