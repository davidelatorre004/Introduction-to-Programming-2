# Plot Twist v01: The rules, without a window

Date: 2026-10-01. Code: commit [`225b24f`](https://github.com/davidelatorre004/Introduction-to-Programming-2/tree/225b24f3336e072e4e639f79591d8f1e603a0d76/plot_twist).

## What changed

- The story as data in `story.py`: five rooms, two items, eight doors, two placeholder puzzles, two endings and every text.
- The rules in `engine.py`: pure functions on a four-key game state (room, inventory, flags, ending), each returning the new state and an outcome.
- `test_engine.py` covers the acceptance scenarios A1-A6, the required capabilities PT01-PT05 and the business rules R1-R4.
- Nothing to see yet: the game is played by the tests only.

## How to try this version

From the folder `Introduction-to-Programming-2`:

```
git checkout 225b24f
cd plot_twist
uv run pytest
```

There is no window in this version: the tests play the game.

To go back to the latest version: `git checkout main`.
