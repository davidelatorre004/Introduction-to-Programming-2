# Plot Twist v03: A window, menus and walking

Date: 2026-10-01. Code: commit [`e2576bc`](https://github.com/davidelatorre004/Introduction-to-Programming-2/tree/e2576bc5394e97bb8ba1113787ac324269eb7ffa/plot_twist).

## What changed

- `main.py` opens the window: a 256 x 224 screen scaled three times.
- Main menu (Resume only with a valid save; a new game asks before replacing one), pause menu and ending screen.
- The player walks with the arrows or WASD and goes through a door by walking into it; a closed door says why, once per push.
- Rooms and things are coloured rectangles for now.

## How to play this version

From the folder `Introduction-to-Programming-2`:

```
git checkout e2576bc
cd plot_twist
uv run python main.py
```

To go back to the latest version: `git checkout claude/funny-ramanujan-ffrx60`.
