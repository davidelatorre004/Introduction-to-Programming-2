# Plot Twist v07: The tiles of the hold and a key in two halves

Date: 2026-10-06. Code: commit [`65ba649`](https://github.com/davidelatorre004/Introduction-to-Programming-2/tree/65ba6499b490925fb9d7ce04a717069880913dc4/plot_twist).

## What changed

- The cabin gives only the first half of the key; a gate bars the hold until the player carries it.
- Five numbered tiles in the hold, walked on in three phases (1-5, then 5-3-1, then 1-5-2-4-3). A wrong tile, or walking out of the grating, starts the phase over with a BZZZ.
- `sounds.py`: sound effects made in code (blip, ding, fanfare, buzz).

## How to play this version

From the folder `Introduction-to-Programming-2`:

```
git checkout 65ba649
cd plot_twist
uv run python main.py
```

To go back to the latest version: `git checkout main`.
