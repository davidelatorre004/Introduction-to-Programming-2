# Plot Twist v11: Phase 1: three new rooms and decor

Date: 2026-11-03. Code: commit [`2db3acf`](https://github.com/davidelatorre004/Introduction-to-Programming-2/tree/2db3acf40302f825c564f62e094d165cc74e7611/plot_twist).

## What changed

- New rooms: the infirmary (west of the hold), the galley (west of the cabin) and the helm.
- A new kind of object, decor: furniture that only adds atmosphere. Some of it blocks the way, some lies flat on the floor.

## How to play this version

From the folder `Introduction-to-Programming-2`:

```
git checkout 2db3acf
cd plot_twist
uv run python main.py
```

To go back to the latest version: `git checkout claude/funny-ramanujan-ffrx60`.
